# Atualização do Workflow BrandOS
## PDF Report Design System: Swiss Editorial Layout

Este arquivo define a atualização da etapa de geração do relatório PDF dentro do workflow do BrandOS.

A partir desta atualização, quando o usuário finalizar o briefing estratégico e escolher gerar o PDF completo, o sistema não deve apenas exportar um documento textual. Ele deve gerar um relatório editorial profissional, estruturado por um sistema visual inspirado no Swiss Design / International Typographic Style.

---

# 1. Onde esta fase entra no workflow

Esta fase acontece depois da etapa em que o usuário termina de responder todas as perguntas do briefing.

O fluxo recomendado é:

```txt
Briefing Estratégico
↓
Consolidação das Respostas
↓
Validação do Briefing pelo Usuário
↓
Output Decision Gate
↓
Escolha do Usuário:
  1. Gerar Relatório PDF Completo
  2. Avançar para Propostas de Layout
  3. Revisar ou Complementar Respostas
↓
Se escolher PDF:
PDF Report Design System: Swiss Editorial Layout
```

---

# 2. Nome oficial da fase

## PDF Report Design System: Swiss Editorial Layout

Esta fase é responsável por transformar todo o conteúdo estratégico coletado no briefing em um relatório PDF completo, editorial, organizado e visualmente profissional.

O PDF deve parecer um documento premium de branding, com linguagem visual clara, sofisticada e estratégica.

Ele não deve parecer:

- Um documento Word exportado.
- Um relatório automático genérico.
- Um texto corrido sem hierarquia.
- Uma apresentação improvisada.
- Um PDF poluído visualmente.

---

# 3. Objetivo da fase

O objetivo desta etapa é gerar um relatório PDF que una:

- Conteúdo estratégico da marca.
- Clareza editorial.
- Organização visual.
- Hierarquia tipográfica.
- Grid modular.
- Espaço em branco.
- Composição profissional.
- Leitura fácil.
- Aparência de sistema de branding.

O PDF deve funcionar como uma entrega final de alto valor, capaz de apresentar o diagnóstico, a estratégia e as diretrizes iniciais da marca de forma clara e visualmente consistente.

---

# 4. Referência visual obrigatória

O relatório deve seguir uma direção visual inspirada no:

## Swiss Design / International Typographic Style

Também conhecido como estilo suíço, esse sistema visual prioriza:

- Clareza.
- Ordem.
- Racionalidade.
- Precisão.
- Hierarquia.
- Grid.
- Tipografia objetiva.
- Uso inteligente do espaço.
- Composição limpa.
- Comunicação direta.

A inspiração não deve ser decorativa. Ela deve orientar a estrutura do documento.

---

# 5. Características obrigatórias do layout

O relatório PDF deve apresentar as seguintes características:

## 5.1 Grid modular

O layout deve ser construído com base em grid.

Regras:

- Usar grid de 6 ou 12 colunas.
- Manter alinhamento consistente entre títulos, textos, números, imagens e blocos.
- Organizar o conteúdo em módulos claros.
- Evitar elementos soltos sem alinhamento.
- Usar o grid para criar ritmo visual.

## 5.2 Alinhamento preciso

O sistema deve priorizar:

- Alinhamento à esquerda.
- Pouco uso de centralização.
- Margens consistentes.
- Blocos organizados.
- Elementos visuais alinhados entre si.

## 5.3 Hierarquia tipográfica forte

O PDF deve ter diferença clara entre:

- Número da seção.
- Título principal.
- Subtítulo.
- Texto de apoio.
- Corpo de texto.
- Citações.
- Destaques.
- Legendas.
- Informações secundárias.

O usuário deve conseguir escanear a página rapidamente e entender o que é mais importante.

## 5.4 Uso generoso de espaço em branco

O relatório deve evitar excesso de conteúdo por página.

Regras:

- Não comprimir grandes blocos de texto.
- Dividir conteúdos longos em páginas ou blocos menores.
- Usar áreas vazias como parte do design.
- Criar respiro entre seções.

## 5.5 Poucas cores

O relatório deve usar uma paleta reduzida.

Preferência:

- Fundo claro.
- Preto.
- Branco.
- Cinzas.
- Uma cor de destaque.

A cor de destaque deve vir da identidade da marca ou ser definida estrategicamente pelo sistema.

## 5.6 Elementos gráficos simples

O relatório pode usar:

- Linhas finas.
- Barras verticais ou horizontais.
- Blocos retangulares.
- Numeração grande.
- Marcadores simples.
- Divisórias.
- Cards informativos.
- Tabelas limpas.
- Áreas de destaque.
- Formas geométricas discretas.

Não usar elementos decorativos excessivos.

# 6. Estrutura recomendada do relatório PDF

O PDF deve conter, sempre que aplicável, as seguintes seções:

## 6.1 Capa

A capa deve apresentar:

- Nome da marca.
- Título do relatório.
- Subtítulo.
- Tipo de entrega.
- Data de geração.
- Elemento gráfico modular ou abstrato.
- Composição limpa e editorial.

Exemplo de título:

```txt
Brand Strategy Report
Nome da Marca
Sistema estratégico e diretrizes iniciais de identidade
```

## 6.2 Sumário

O sumário deve apresentar as seções de forma clara.

Regras:

- Numeração visível.
- Títulos curtos.
- Alinhamento em grid.
- Espaçamento generoso.
- Visual limpo.

## 6.3 Introdução

A introdução deve explicar:

- O contexto da marca.
- O objetivo do projeto.
- O que o relatório apresenta.
- Como o documento deve ser usado.

## 6.4 Diagnóstico estratégico

Esta seção deve consolidar:

- Respostas principais do briefing.
- Contexto do negócio.
- Problema ou oportunidade.
- Objetivos da marca.
- Mercado.
- Concorrência.
- Diferenciais percebidos.
- Desafios identificados.

## 6.5 Núcleo da marca

Esta seção deve apresentar:

- Propósito.
- Missão.
- Visão.
- Valores.
- Essência.
- Personalidade.
- Promessa central.
- Crenças da marca.

## 6.6 Posicionamento

Esta seção deve apresentar:

- Declaração de posicionamento.
- Território de marca.
- Proposta de valor.
- Diferenciais competitivos.
- Percepção desejada.
- Mensagem central.

## 6.7 Público e personas

Esta seção deve apresentar:

- Público-alvo principal.
- Segmentos de público.
- Dores.
- Desejos.
- Barreiras.
- Motivações.
- Personas, se aplicável.

## 6.8 Universo verbal

Esta seção deve apresentar:

- Tom de voz.
- Linguagem da marca.
- Palavras recomendadas.
- Palavras a evitar.
- Mensagens-chave.
- Exemplos de frases.
- Estilo de comunicação.

## 6.9 Universo visual

Esta seção deve apresentar diretrizes visuais iniciais, como:

- Direção visual.
- Estilo gráfico.
- Paleta sugerida.
- Tipografia sugerida.
- Estilo fotográfico.
- Elementos gráficos.
- Atmosfera visual.
- Referências de composição.

## 6.10 Diretrizes de aplicação

Esta seção deve explicar como a marca pode ser aplicada em:

- Redes sociais.
- Landing pages.
- Apresentações.
- Materiais comerciais.
- Aplicativos.
- Produtos digitais.
- Peças institucionais.
- Campanhas.

## 6.11 Recomendações estratégicas

Esta seção deve trazer:

- Próximos passos.
- Pontos de atenção.
- Oportunidades.
- Cuidados de consistência.
- Sugestões de evolução.
- Materiais futuros recomendados.

## 6.12 Encerramento

O encerramento deve resumir:

- A essência da marca.
- A direção estratégica.
- O valor do sistema criado.
- A próxima etapa sugerida.

# 7. Tipos de páginas do relatório

O sistema deve montar o PDF usando diferentes tipos de página para criar ritmo editorial.

## 7.1 Página de abertura de seção

Usada para iniciar uma nova parte do relatório.

Características:

- Número grande da seção.
- Título forte.
- Subtítulo curto.
- Poucos elementos.
- Muito espaço em branco.

## 7.2 Página de conteúdo estratégico

Usada para explicar conceitos e decisões.

Características:

- Título claro.
- Texto dividido em blocos.
- Cards ou colunas.
- Destaques visuais.

## 7.3 Página de insight

Usada para destacar uma ideia importante.

Características:

- Frase principal grande.
- Pouco texto.
- Forte contraste.
- Composição limpa.

## 7.4 Página de tabela ou comparação

Usada para organizar informações comparativas.

Características:

- Tabela simples.
- Linhas finas.
- Poucas cores.
- Boa legibilidade.

## 7.5 Página de diretrizes

Usada para apresentar regras de uso da marca.

Características:

- Blocos objetivos.
- Exemplos práticos.
- Organização modular.

## 7.6 Página visual

Usada para referências, moodboards ou direções visuais.

Características:

- Imagens alinhadas ao grid.
- Legendas curtas.
- Composição limpa.
- Pouca interferência decorativa.

---

# 8. Sistema tipográfico

O sistema deve escolher uma tipografia limpa, moderna e legível.

Preferência:

- Fontes sem serifa.
- Boa leitura em PDF.
- Aparência editorial.
- Alto contraste entre pesos.

Regras:

- Usar no máximo 2 famílias tipográficas.
- Definir tamanhos diferentes para título, subtítulo, corpo e legenda.
- Criar hierarquia visual clara.
- Evitar fontes decorativas.
- Evitar excesso de estilos.

Sugestão de hierarquia:

```txt
Título de capa: muito grande
Título de seção: grande
Título de página: médio/grande
Subtítulo: médio
Corpo de texto: legível
Legenda: pequena
Dados secundários: pequena ou média
```

---

# 9. Sistema de cores

O PDF deve usar um sistema de cor simples.

Base recomendada:

```txt
Fundo: branco ou off-white
Texto principal: preto ou grafite
Texto secundário: cinza
Linhas/divisórias: cinza claro
Cor de destaque: cor principal da marca
```

Regras:

- Não usar muitas cores ao mesmo tempo.
- Não usar gradientes excessivos.
- Não usar fundos coloridos em excesso.
- Usar cor para orientar leitura, não apenas decorar.
- Manter consistência entre as páginas.

---

# 10. Componentes visuais recorrentes

O sistema deve usar componentes consistentes ao longo do PDF.

Componentes recomendados:

## 10.1 Header editorial

Pode conter:

- Nome da marca.
- Nome da seção.
- Número da página.
- Categoria do conteúdo.

## 10.2 Numeração de seção

Usar números grandes para organizar o relatório.

Exemplo:

```txt
01
Diagnóstico Estratégico
```

## 10.3 Cards informativos

Usar para destacar:

- Insights.
- Valores.
- Características da marca.
- Recomendações.
- Resumos.

## 10.4 Barras e linhas

Usar para:

- Separar blocos.
- Guiar leitura.
- Criar ritmo visual.
- Reforçar o grid.

## 10.5 Blocos de destaque

Usar para frases importantes, como:

- Promessa da marca.
- Essência.
- Posicionamento.
- Mensagem central.

---

# 11. Regras de escrita dentro do PDF

O conteúdo do relatório deve ser:

- Claro.
- Estratégico.
- Profissional.
- Didático.
- Organizado.
- Sem excesso de jargões.
- Fácil de entender.
- Adequado ao nível do usuário.

O sistema deve explicar conceitos quando necessário, principalmente se o usuário demonstrar que é iniciante.

Evitar:

- Linguagem genérica.
- Textos vagos.
- Frases muito longas.
- Termos técnicos sem explicação.
- Repetição excessiva.
- Conteúdo que parece preenchimento automático.

---

# 12. Regras de qualidade visual

Antes de finalizar o PDF, o sistema deve revisar:

- Se as páginas têm hierarquia clara.
- Se o grid está consistente.
- Se o texto está legível.
- Se há espaço em branco suficiente.
- Se as seções estão bem separadas.
- Se os títulos estão fortes.
- Se a paleta está consistente.
- Se o relatório parece profissional.
- Se não parece um documento genérico.

---

# 13. O que o sistema deve evitar

O sistema não deve gerar o PDF com:

- Texto corrido demais.
- Páginas muito cheias.
- Layout desalinhado.
- Excesso de cores.
- Excesso de ícones.
- Fontes decorativas.
- Muitas variações tipográficas.
- Imagens sem critério.
- Elementos aleatórios.
- Aparência de template genérico.
- Visual parecido com documento Word.
- Falta de hierarquia.
- Falta de respiro.
- Falta de consistência.

---

# 14. Prompt interno da fase

Use este prompt como instrução interna para o Claude ou para o agente responsável pela geração do relatório:

```txt
Quando o usuário escolher gerar o relatório PDF completo, ative a fase "PDF Report Design System: Swiss Editorial Layout".

Transforme todas as respostas coletadas no briefing em um relatório editorial profissional de branding.

O relatório deve seguir uma estética inspirada no Swiss Design / International Typographic Style, com grid modular, hierarquia tipográfica forte, alinhamento preciso, uso generoso de espaço em branco, composição limpa e linguagem visual sofisticada.

Não gere apenas um documento textual. Gere um relatório com estrutura editorial, seções claras, tipos de página variados, componentes visuais recorrentes e organização profissional.

O PDF deve conter, sempre que aplicável: capa, sumário, introdução, diagnóstico estratégico, núcleo da marca, posicionamento, público/personas, universo verbal, universo visual, diretrizes de aplicação, recomendações estratégicas e encerramento.

Antes de finalizar, revise se o documento tem clareza, consistência visual, boa legibilidade, respiro, hierarquia e aparência de entrega premium de branding.
```

# 15. Integração com o Output Decision Gate

Esta fase deve ser conectada ao momento de decisão após o briefing.

Use a seguinte regra:

```txt
Se o usuário finalizar o briefing e escolher "Gerar PDF completo", o sistema deve acionar a fase PDF Report Design System: Swiss Editorial Layout.

Se o usuário escolher "Avançar para propostas de layout", o sistema deve acionar a fase Layout Proposal Studio.

Se o usuário escolher "Revisar respostas", o sistema deve retornar ao briefing e permitir edição, complemento ou correção.
```
