# Teste — Marca Nova

**Caso:** Track Running  
**Tipo:** Marca nova com potencial de produto digital futuro

---

## Entrada de teste

```
Marca: Track Running
Segmento: esporte, corrida e fitness
Objetivo: criar uma marca para depois criar um app de treinos por IA.
```

---

## Checklist de validação

### Identificação e Discovery

- [ ] O sistema identificou corretamente que é uma marca nova
- [ ] O sistema identificou o potencial de produto digital futuro
- [ ] O Discovery coletou informações suficientes para avançar
- [ ] O sistema não gerou brand system sem briefing completo

### Pesquisa e Público

- [ ] A pesquisa mapeou concorrentes relevantes (Strava, Nike Run Club, etc.)
- [ ] O sistema identificou padrões visuais da categoria (cores de esporte/tech)
- [ ] As personas mapearam corredores iniciantes e intermediários
- [ ] O público-alvo não ficou genérico demais

### Estratégia

- [ ] O posicionamento é específico para corrida + tecnologia
- [ ] O posicionamento não é genérico de academia/fitness
- [ ] A proposta de valor diferencia de apps concorrentes
- [ ] O Brand DNA foi aprovado antes de avançar para verbal/visual

### Identidade Verbal

- [ ] O tom é motivador sem ser exagerado
- [ ] O vocabulário conversa com corredores, não com atletas de elite
- [ ] A tagline é memorável e específica para a marca

### Identidade Visual

- [ ] A direção visual transmite movimento, ritmo e tecnologia
- [ ] A paleta diferencia de concorrentes diretos
- [ ] O estilo não parece genérico de academia

### Fase UX

- [ ] O sistema acionou ou recomendou a fase UX + Product Experience
- [ ] Houve orientação sobre a evolução futura para app

### Qualidade

- [ ] Score ≥ 80
- [ ] Gate 12 aprovado
- [ ] Brand book completo gerado

---

## Resultado esperado

- Marca esportiva moderna com estratégia clara
- Tom motivador e acessível
- Direção visual com energia, movimento e tecnologia
- Potencial de produto digital documentado
