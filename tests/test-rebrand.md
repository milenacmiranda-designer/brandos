## Checklist de validação

### Identificação e Audit

- [ ] O sistema identificou que é uma marca existente
- [ ] O sistema ativou a fase Brand Context (auditoria)
- [ ] A auditoria foi respeitosa com o trabalho existente
- [ ] O sistema identificou o que preservar e o que mudar

### Pesquisa e Público

- [ ] O sistema mapeou concorrentes locais relevantes
- [ ] O público mapeado incluiu famílias e casais
- [ ] O sistema considerou os canais reais (Instagram, WhatsApp)

### Estratégia

- [ ] O posicionamento tem foco em confiança e relacionamento
- [ ] O posicionamento é realista para um negócio local
- [ ] A proposta de valor é comercialmente direta
- [ ] O Brand DNA foi aprovado antes de avançar

### Identidade Verbal

- [ ] O tom é próximo e acolhedor, não corporativo
- [ ] A linguagem é simples o suficiente para WhatsApp e Instagram
- [ ] Os exemplos de comunicação são práticos para a realidade do negócio
- [ ] Não usou jargão de design que o dono não usaria

### Identidade Visual

- [ ] A paleta é calorosa e profissional
- [ ] A direção visual funciona em Instagram e materiais físicos
- [ ] Não é uma estética genérica de "empresa local"

### Qualidade

- [ ] Score ≥ 70
- [ ] Gate 12 aprovado
- [ ] Brand book completo e aplicável na prática
