# Skill — Positioning

**Tipo:** Skill reutilizável  
**Usada por:** `strategy-agent`, `brand-dna-agent`

---

## O que esta skill faz

Define o posicionamento estratégico da marca com base no briefing, personas e contexto de mercado.

---

## Quando usar

- Fase de Strategy Flow (fase 7)
- Antes de qualquer decisão de identidade verbal ou visual
- Quando o posicionamento existente precisar ser revisado

---

## Framework de posicionamento

```
A [nome] se posiciona como [categoria]
para [público prioritário],
oferecendo [benefício principal],
por meio de [diferencial],
para gerar [resultado desejado].
```

---

## Componentes que esta skill define

| Componente | O que é |
|------------|---------|
| Categoria | Como a marca se classifica no mercado |
| Público prioritário | A persona principal |
| Promessa | O que a marca entrega |
| Benefício central | O resultado para o usuário |
| Diferencial | O que torna única no segmento |
| Razão para acreditar | Por que confiar nessa promessa |
| Território de marca | O espaço conceitual que ocupa |
| Inimigo conceitual | O que a marca supera ou combate |

---

## Processo

```
1. Sintetizar briefing + personas + pesquisa de mercado
2. Identificar lacunas de posicionamento no mercado
3. Definir território de marca (onde há espaço)
4. Redigir declaração de posicionamento (usando o framework)
5. Validar: é específico? Defensável? Relevante? Aplicável?
6. Gerar implicações para comunicação e visual
```

---

## Teste de qualidade

O posicionamento deve passar em 4 perguntas:

1. **Específico?** Não serve para qualquer empresa do setor.
2. **Defensável?** A marca consegue sustentar essa promessa.
3. **Relevante?** O público-alvo se importa com isso.
4. **Aplicável?** Gera comunicação e visual concretos.

---

## O que evitar

- "Qualidade e inovação" como diferenciais
- Posicionamento que qualquer concorrente poderia usar
- Promessas não sustentáveis pelo produto
- Posicionamento baseado apenas em estética
