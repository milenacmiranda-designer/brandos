# Skill — Brand Audit

**Tipo:** Skill reutilizável  
**Usada por:** `brand-context-agent`

---

## O que esta skill faz

Avalia marcas existentes para identificar pontos fortes, pontos fracos, inconsistências e oportunidades de melhoria.

---

## Quando usar

- Quando o projeto for redesign, reposicionamento ou melhoria de marca
- Quando o usuário trouxer materiais de uma marca existente
- Antes de definir nova estratégia para uma marca que já existe

---

## Dimensões de avaliação

| Dimensão | O que analisa |
|----------|--------------|
| Proposta | A marca comunica claramente o que faz e para quem? |
| Posicionamento | A marca tem espaço claro e diferencial? |
| Público | A comunicação conversa com o público certo? |
| Visual | A identidade visual é coerente e aplicada? |
| Verbal | O tom de voz é consistente e autêntico? |
| Consistência | Os elementos funcionam juntos? |
| Aplicabilidade | A marca funciona bem nos canais reais? |
| Percepção | Como o público provavelmente percebe a marca? |

---

## Processo

```
1. Coletar materiais disponíveis (links, descrições, imagens)
2. Avaliar cada dimensão com nota qualitativa:
   - Forte
   - Médio
   - Fraco
   - Ausente
3. Identificar inconsistências entre dimensões
4. Mapear o que deve permanecer (ativos de marca)
5. Mapear o que deve mudar (pontos críticos)
6. Gerar diagnóstico com recomendações priorizadas
```

- Sugerir mudança de tudo de uma vez
