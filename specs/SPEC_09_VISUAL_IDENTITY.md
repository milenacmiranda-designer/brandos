# SPEC_09_VISUAL_IDENTITY — Identidade Visual Conceitual

## Objetivo

Criar a direção visual conceitual da marca — estratégica, não executiva.

## Escopo desta spec

Esta spec cobre **direção visual conceitual**, não execução gráfica. O BrandOS não cria arquivos vetoriais, mas define com precisão o que o designer ou tool de criação deve executar.

## Entrada necessária

- posicionamento aprovado
- personalidade da marca (Brand DNA aprovado)
- personas
- segmento
- referências visuais do usuário
- restrições visuais (cores que não usar, estilos a evitar)
- percepção desejada pelo público
- canais de aplicação (Instagram, site, embalagem, app...)

## Processo

O agente deve definir:

1. conceito visual central (a ideia que orienta as escolhas)
2. atmosfera estética (como a marca deve se sentir visualmente)
3. paleta de cores (primária, secundária, neutros)
4. tipografias sugeridas (família, uso, hierarquia)
5. estilo gráfico (minimalista, orgânico, geométrico...)
6. estilo fotográfico (editorial, lifestyle, produto, ilustração...)
7. elementos visuais característicos (formas, texturas, padrões)
8. composição e ritmo visual
9. aplicações principais recomendadas

## Saída esperada

A entrega deve conter:

- conceito visual com justificativa estratégica
- atmosfera estética descrita em palavras e referências
- paleta sugerida com códigos de cores (HEX)
- tipografias sugeridas com uso (títulos, corpo, destaque)
- estilo gráfico definido com exemplos
- estilo fotográfico com referências descritivas
- elementos visuais característicos
- recomendações de aplicação por canal
- prompts visuais para geração de imagens (quando aplicável)

## Critérios de qualidade

A direção visual deve:

- traduzir a estratégia e a personalidade para o visual
- conversar diretamente com o público-alvo
- diferenciar a marca dos concorrentes
- ser aplicável em canais reais sem adaptações drásticas
- explicar o motivo de cada decisão (não apenas dizer "use azul")
- evitar escolhas aleatórias ou baseadas em tendência sem conexão

## O que evitar

- Escolher cores apenas por gosto pessoal ou moda
- Sugerir fontes sem justificativa de personalidade
- Criar uma estética genérica "moderna e clean"
- Copiar referências diretamente sem conceitualizar
- Ignorar os canais reais de aplicação
